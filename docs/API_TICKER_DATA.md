# 标的数据查询接口文档

## 接口信息

- **接口路径**: `/api/ticker/data`
- **请求方法**: `GET`
- **接口描述**: 查询标的的实时数据，先从 Kafka 查询，查询不到则从 Redis 查询

---

## 请求参数

### Query 参数

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|--------|
| stock_code | string | 是 | 股票代码或加密货币代码 | `000001` 或 `BTCUSDT` |
| market | string | 是 | 市场代码（SH/SZ/HK）。对于加密货币，可以为空字符串 | `SH` 或 `""` |

### market 参数说明

| 值 | 说明 | 示例股票代码 |
|----|------|-------------|
| SH | 沪市（上海证券交易所） | 000001, 600000, 600036 |
| SZ | 深市（深圳证券交易所） | 000002, 000858, 002415 |
| HK | 港股（香港交易所） | 00700, 09988, 03690 |

**注意**: 本接口不支持北交所（BJ）股票查询。

## 加密货币查询

本接口 `/api/ticker/data` 支持加密货币查询。加密货币数据仅从 Kafka 获取，不支持 Redis 查询。

### 加密货币查询方式

使用 GET 方法，传入加密货币代码，market 参数可以为空字符串：

#### CMD 命令

```cmd
curl "http://localhost:8000/api/ticker/data?stock_code=BTCUSDT&market="
```

#### PowerShell 命令

```powershell
Invoke-RestMethod -Uri "http://localhost:8000/api/ticker/data?stock_code=BTCUSDT&market="
```

### 支持的加密货币代码

| 代码 | 说明 | 示例 |
|------|------|------|
| BTCUSDT | 比特币/USDT | `BTCUSDT` |
| ETHUSDT | 以太坊/USDT | `ETHUSDT` |

### 加密货币查询示例

#### 查询 BTC/USDT
```cmd
curl "http://localhost:8000/api/ticker/data?stock_code=BTCUSDT&market="
```

#### 查询 ETH/USDT
```cmd
curl "http://localhost:8000/api/ticker/data?stock_code=ETHUSDT&market="
```

### 加密货币数据说明

- **数据源**: 加密货币数据仅从 Kafka 获取，不支持 Redis 查询
- **超时时间**: 加密货币查询超时时间为 30 秒（比股票查询更长）
- **market 参数**: 查询加密货币时，`market` 参数可以为空字符串 `""` 或省略
- **自动识别**: 接口会自动识别加密货币代码（如 BTCUSDT、ETHUSDT 等）

## 响应格式

### 响应结构

```json
{
    "code": "000000",
    "message": "获取成功",
    "data": {
        // 标的的数据对象
    }
}
```

### 响应字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| code | string | 响应码，`000000` 表示成功，其他表示失败 |
| message | string | 响应消息 |
| data | object | 标的的数据对象，成功时包含数据，失败时为空对象 `{}` |

### 响应码说明

| 响应码 | 说明 |
|--------|------|
| 000000 | 获取成功 |
| 100001 | 未获取到标的数据（Kafka 和 Redis 中都没有找到） |
| 100002 | 查询失败（系统错误） |

## 数据查询逻辑

### 股票/指数查询流程

1. **优先从 Kafka 查询**: 接口首先尝试从 Kafka 实时消费数据（等待最多 5 秒）
2. **降级到 Redis**: 如果 Kafka 中没有找到数据，则从 Redis 查询缓存数据
3. **返回结果**: 如果两个数据源都没有数据，返回 `100001` 错误码

### 加密货币查询流程

1. **仅从 Kafka 查询**: 加密货币数据仅从 Kafka 实时消费（等待最多 30 秒）
2. **不支持 Redis**: 加密货币不支持 Redis 查询
3. **返回结果**: 如果 Kafka 中没有找到数据，返回 `100001` 错误码

---

## 注意事项

1. **数据实时性**: Kafka 数据为实时数据，Redis 数据为缓存数据，可能存在延迟
2. **股票代码格式**: 
   - A股（SH/SZ）: 6位数字，如 `000001`, `600000`
   - 港股（HK）: 5位数字，如 `00700`, `09988`
   - 加密货币: 如 `BTCUSDT`, `ETHUSDT`
3. **市场代码**: 
   - 股票必须与股票代码匹配（SH/SZ/HK）
   - 加密货币的 market 参数可以为空字符串 `""` 或省略
4. **超时时间**: 
   - 股票/指数查询超时时间为 5 秒，如果 5 秒内没有数据，会自动降级到 Redis
   - 加密货币查询超时时间为 30 秒
5. **数据源**: 
   - 股票/指数：先从 Kafka 查询，查询不到再从 Redis 查询
   - 加密货币：仅从 Kafka 查询，不支持 Redis
6. **不支持的市场**: 本接口不支持北交所（BJ）股票查询

## 错误处理

### 常见错误

1. **参数缺失**: 如果缺少 `stock_code` 或 `market` 参数，会返回 422 验证错误
2. **股票不存在**: 如果股票代码不存在或市场代码不匹配，返回 `100001`
3. **服务异常**: 如果系统出现异常，返回 `100002` 并包含错误详情

### 错误排查

1. 检查股票代码是否正确
2. 检查市场代码是否匹配（SH/SZ/HK，加密货币可以为空）
3. 检查服务是否正常运行
4. 查看服务日志获取详细错误信息
5. **加密货币查询**: 使用本接口即可，传入加密货币代码（如 BTCUSDT），market 参数可以为空
